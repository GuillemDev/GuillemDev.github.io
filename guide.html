How to fill this portfolio

You don't need to touch the HTML. Every text, image and video lives in one file: js/projects.js. You can delete this page when you're done (and remove guide.html from the repository).

1. Your name, intro and links

At the top of js/projects.js is the SITE block. Change the text between the quotes.

window.SITE = {
  name: "Your Name",
  tagline: "One line that sells you.",
  about: "Two or three sentences about you.",
  email: "you@example.com",
  links: [ { label: "GitHub", url: "https://github.com/your-user" } ]
};

2. A project module

Each project is one block like the one below. This is what it looks like once rendered:

And this is the code that produced it:

{
  title: "Title of the project",
  subtitle: "Subtitle: engine, role, year",
  description: "First paragraph.\n\nSecond paragraph.",
  media: { type: "image", src: "assets/images/my-game.jpg", alt: "What the image shows" },
  link: { label: "Play on itch.io", url: "https://..." }   // optional
},
  • Blocks are separated by a comma. Missing commas or quotes are the most common errors.
  • To add a project, copy a whole block { ... }, and paste it in the list you want. To remove one, delete its block.
  • Modules show in the same order you write them.
  • For a line break use \n\n inside the description (it creates a new paragraph).

3. Images

  1. Put the file in the assets/images/ folder (JPG, PNG or WebP; under 500 KB each is ideal).
  2. Use simple names: lowercase, no spaces, e.g. my-game.jpg.
  3. Reference it:
media: { type: "image", src: "assets/images/my-game.jpg", alt: "Short description" }

The frame is widescreen (2.39:1, like a cinema film). Wide images look best; others are cropped to fit.

4. Videos

Option A: YouTube (recommended). Upload to YouTube (unlisted works). From the link https://www.youtube.com/watch?v=dQw4w9WgXcQ copy only the code after v=:

media: { type: "youtube", src: "dQw4w9WgXcQ" }

Option B: a video file. Put an MP4 (H.264) in assets/videos/. GitHub rejects files over 100 MB and recommends repositories under 1 GB, so keep clips short and compressed.

media: { type: "video", src: "assets/videos/my-trailer.mp4", poster: "assets/images/my-trailer-cover.jpg" }

5. Which list is which page?

  • top3 is the page Top 3 Projects

  • godot is the page Godot Projects

6. Check your changes

Edit the file on GitHub (pencil icon), commit it, and wait 1 to 2 minutes. Then refresh your site with Ctrl+F5. If a page looks empty, there is probably a missing comma or quote in projects.js: press F12 in the browser and look at the Console for the line number.
